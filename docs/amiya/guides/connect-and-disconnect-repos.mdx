## Connecting a Repository

Once your GitHub account is linked, you can connect a GitHub repository to a Discord forum channel, given that you have provided the app access to the repository. To connect a repository, use the `/gitthread sync connect` command. You will be prompted to select a forum channel and a GitHub repository to connect.

![](./assets/repo-connect.webp)

Now that the repository is connected, any issues or threads created will be synced between the two platforms.

![](./assets/thread-example.webp)

![](./assets/issue-example.webp)

## Disconnecting a Repository

You can disconnect a repository from a forum channel using the `/gitthread sync disconnect` command. You will be prompted to select the forum channel and the repository you want to disconnect. This will not delete any existing threads or issues, but it will stop syncing new ones between the two platforms.

![](./assets/repo-disconnect.webp)
