Amiya is a bot that allows you to sync Discord threads and GitHub issues. This documentation will serve as a guide for setting up and using Amiya.

## Features

Some of the features of Amiya include:

- Automatically creating issues from threads and vice versa.
- Manually adding issues to threads and vice versa (via commands).
- Locking and unlocking issues from threads and vice versa (via commands).
- Closing and reopening issues from threads and vice versa (via commands).

## Limitations

The bot does not fully support all Discord and GitHub features. Some limitations include:

- Locking/Closing threads will not lock/close the corresponding issue, see [here](./guides/sync-commands.mdx) for more information.
- No syncing comments from threads or issues.
- No image support for threads or issues.
- No label support for threads or issues.
