Contributions can be more than new pages. Fixing incorrect steps, replacing an
old screenshot, or making a sentence easier to understand also helps.

## Before You Start

You should have a basic understanding of how Fumadocs and MDX work. Read their
documentation before contributing:

- [Fumadocs documentation](https://www.fumadocs.dev/docs)
- [MDX documentation](https://mdxjs.com/docs/)

## Previewing Changes

Currently there is no way to preview your changes until your pull request is
merged. You can use [Fumadocs Editor](https://editor.fumadocs.dev/) to preview
how some MDX will look. The editor does not include this site's custom
components or other custom features.

After your pull request is merged, the changes appear on the
[preview website](https://docs.timeworn.dev/).
