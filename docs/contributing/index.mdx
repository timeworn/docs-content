Contributions can be more than new pages. Fixing incorrect steps, replacing an
old screenshot, or making a sentence easier to understand also helps.

## Before You Start

You should have a basic understanding of how Fumadocs and MDX works. You can
find them here:

- [Fumadocs](https://www.fumadocs.dev/docs)
- [MDX](https://mdxjs.com/docs/)

## Previewing Changes

Currently there is no way to preview your changes. You can use
[Fumadocs Editor](https://editor.fumadocs.dev/) to preview how some mdx will
look like. This does not include the custom components and other features this
site has.

If your pull request has been merged, you can find it on the
[preview domain](https://docs.timeworn.dev/).
