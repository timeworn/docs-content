---
title: Text Formatting
description: Guidelines for formatting text.
---

Text formatting should make a page easier to read. If too many words or phrases
are formatted, nothing stands out.

## Bold

Use bold for UI elements, headings, and emphasis.

```mdx
Select **Save Changes**.

Do **not** close the launcher while files are being copied.
```

> Select **Save Changes**.
>
> Do **not** close the launcher while files are being copied.

Do not bold entire paragraphs or sentences, it makes the page harder to read.

## Italic

Use italics for the title of a book, movie, game, or other work that is not a
link.

```mdx
You should read _Omniscient Reader's Viewpoint_.
```

> You should read _Omniscient Reader's Viewpoint_.

Italics can be used for emphasis, but it is generally better to use bold.

## Underline

Do not use underlines, they are reserved for links.

## Strikethrough

Do not use strikethrough, remove the text instead.

## Inline Code

Use inline code for files, text that the reader enters, or code-related text.

- CLI command: `npm run dev`
- File and folder names: `meta.json`, `docs/contributing/`
- File paths: `%localappdata%\RevivalSide`
- Environment variables: `BOT_TOKEN`
- Class, function, and property names: `Command`, `initialUrl`
- API routes and values: `/get/{slug}`, `true`
- Placeholders: `<your-token>`

Do not use inline code for emphasis or to highlight a word.

| Avoid                                             | Prefer                                          |
| ------------------------------------------------- | ----------------------------------------------- |
| Select `Save Changes`.                            | Select **Save Changes**.                        |
| Open **meta.json**.                               | Open `meta.json`.                               |
| The `GitHub` repository contains the source code. | The GitHub repository contains the source code. |

## Keyboard Keys

Use `<kbd>` for keyboard keys.

```mdx
Press <kbd>Ctrl</kbd>+<kbd>C</kbd> to stop a process.
```

> Press <kbd>Ctrl</kbd>+<kbd>C</kbd> to stop a process.
