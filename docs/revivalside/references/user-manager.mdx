---
title: User Manager
---

The User Manager is a browser-based tool for managing saved accounts. It allows you to view, edit, and delete accounts that have been imported or created by RevivalSide. You can also use the User Manager to export account data to a JSON file for backup or sharing purposes.

![](./assets/user-manager.webp)

## Opening the User Manager

<Callout>
  The server must be running in order to use the User Manager.
</Callout>

You can open the User Manager by clicking on the "User Manager" button in the "Home" tab of the RevivalSide launcher. This will open a new window in your browser where you can view and manage your saved accounts.

![](./assets/user-manager-btn.webp)
