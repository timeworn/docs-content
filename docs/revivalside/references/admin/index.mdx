RevivalSide has a built-in admin commands that allows you to manage the server and give yourself items and units.

![](./assets/command-example.webp)

## Opening the Admin Chat

<Steps>
<Step>

### Open HanaTalk

In the game's main menu, click on the "HanaTalk" button to open the chat window.

![](./assets/main-menu-hanatalk.webp)

</Step>
<Step>

### Open "RevivalSide Admin" Chat

Once HanaTalk is open, click on the message icon next to "Revival Admin" so that you can send messages to the console.

![](./assets/hanatalk.webp)

</Step>
</Steps>

## Using Commands

In order to use the admin commands, you will need to type them into the chat box in HanaTalk. If you are unsure of what commands are available, you can type `/help` to see a list of all the commands you can use.

![](./assets/command-help.webp)

### Parameters

Some commands require parameters in order to work. Parameters are additional information that you provide to the command in order to specify what you want it to do. For example, the `/give currency` command requires a parameter for the type of currency (`<credits|eternium|quartz|admincoins|id>`) and the amount you want to give (`<count>`).

#### Rules

- `<angle brackets>` indicate a required parameter.
- `[square brackets]` indicate an optional parameter.
- `[flag=value]` indicates an optional flag that has a default value if not specified.
- `[flag=name:value]` indicates an optional flag with a name and a value.
- `|` indicates a choice between multiple options.
- `...` indicates that you can repeat the previous parameter multiple times.
- Optional parameters may be given positionally. Once you use `flag=value` syntax, all subsequent parameters must also use `flag=value` syntax.

#### Examples

<Callout>
  The following command does not exist and is only used for clarification
  purposes.
</Callout>

```
/give item <player> <item_id> [rarity=legendary] [level=1] [substat=name:value ...]
```

Given the command above, the following are valid:

```
/give item user 1001
/give item user 1001 legendary 50
/give item user 1001 legendary level=50
/give item user 1001 rarity=legendary level=50
/give item user 1001 level=50 rarity=legendary

/give item user 1001 legendary 50 substat=attack:1000
/give item user 1001 legendary 50 substat=attack:1000 substat=defense:500
/give item user 1001 legendary level=50 substat=attack:1000
/give item user 1001 level=50 rarity=legendary substat=attack:1000
```

The following are invalid:

```
/give item user
/give item 1001
/give item user 1001 50 legendary
/give item user 1001 level=50 legendary
```

## Tips

- Use the RevivalSide wiki to look up IDs for units, items, gear, skins, and more.
- Make backups of your save before running any risky command such as `/give all`!
