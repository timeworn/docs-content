## Installing RevivalSide

Head over to the [releases](https://github.com/MadlyMoe/RevivalSide/releases/latest) page on GitHub and download the latest version of the launcher. Currently, the launcher is only available for Windows and Android. Once you have downloaded the launcher, run it and follow the prompts to install RevivalSide.

### Windows

<Callout>
  The default installation path is `%localappdata%\RevivalSide`.
</Callout>

For Windows, download the `RevivalSideSetup.exe` file and run it.

![](./assets/github-page.webp)

Follow the prompts to install RevivalSide.

![](./assets/installer.webp)

Once the installation is complete, it should automatically start the RevivalSide launcher.

![](./assets/launcher-games.webp)

Now that you have the launcher installed, before you can play, you need to "freeze" the client. This allows you to play CounterSide offline. To do this, click the hamburger menu next to the "Start Game" button and click "Game Settings".

![](./assets/game-settings.webp)

This should open a popup window. From here, find the "CounterSide source client" section and click the "Detect CounterSide" button. This will try to find CounterSide's `Assembly-CSharp.dll` file. If it cannot find it, please press "Browse DLL" and locate the `Assembly-CSharp.dll` file manually. This file is usually located in the `CounterSide\Data\Managed` folder of your CounterSide installation.

![](./assets/select-client.webp)

After the client has been detected, the "Freeze Selected Client" button should become available. Click it to freeze the client. Once it is complete, it should say "Frozen client ready for verified local..." in the "Home" tab of the launcher.

![](./assets/freeze-client-ready.webp)

<Callout type="idea">
You can check the progress of "Freeze Selected Client" in the "Logs" tab of the launcher. This also applies to other processes such as starting the server and wiki.
</Callout>

![](./assets/freeze-progress.webp)
